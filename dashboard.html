Communications & API Gateway

SMS & Email Notification Settings

📱 Semaphore.co (Philippine SMS)

Sends auto-SMS to patient mobile numbers when appointment is confirmed.

Config Ready

When staff confirms an appointment, the system automatically sends:
"O'Clear Dental Clinic: Hello {Patient}! Your appointment for {Procedure} on {Date} at our Arayat, Pampanga clinic is now CONFIRMED by Dr. Claire. Clinic Line: 0927-136-0441."

How to activate live SMS:

  1. Log in to your account at Semaphore.co
  2. Go to Account Settings → API Keys
  3. Copy your API Key and paste it into config.json:
    "SEMAPHORE_API_KEY": "YOUR_KEY_HERE"

✉️ Resend.com (Email Notifications)

Sends luxury HTML confirmation emails (Free tier: 3,000/mo).

Config Ready

Sends an official dental confirmation letter with the O'Clear Clinic branding, schedule, location in Arayat, Pampanga, and preparation tips.

How to activate live Email:

  1. Sign up for free at Resend.com
  2. Click API Keys → Create API Key (begins with re_...)
  3. Paste into config.json:
    "RESEND_API_KEY": "re_..."

⚡ PayMongo Payment Gateway (GCash / Maya / Card)

Accept online payments directly with automated processing fee markups.

Gateway Ready

Generate one-click payment links for your patients. Supports GCash, Maya, GrabPay, and Credit/Debit cards. Includes automated simulation mode and live API mode.

How to activate live PayMongo:

  1. Log in to your account at dashboard.paymongo.com
  2. Go to Developers → API Keys
  3. Copy your Secret Key (sk_live_... or sk_test_...) and paste into config.json:
    "PAYMONGO_SECRET_KEY": "sk_..."
